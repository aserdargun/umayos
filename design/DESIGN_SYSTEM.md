# UMAY OS visual specification

Nine fresh section references in `concepts/` define the visual family. References are design evidence, never page raster backgrounds. Three separate production assets in `originals/` are optimized for the actual site.

- Navy #0B1F3A, teal #20B8BE, pure white #FFFFFF. Dark teal #087B80 is the accessible text accent on white. No color wash over artwork; edge masks blend navy artwork into the hero.
- Inter Variable, locally bundled Latin and Latin Extended; SIL OFL 1.1. Headings 72–80px desktop, 30–36px phone; body 17–20px; controls 15–16px with explicit weight/line height. Three unbroken hero lines in both languages.
- Maximum content width 1400px, desktop gutters 64px, mobile 20px. Hero title 88px at the 1536px reference width, hero controls 17px/62px. Section spacing 100–120px desktop, 64–72px mobile. Hairline rules; square controls; no repeating boxed card grid. The last native-size comparison corrected the initial overly narrow container and undersized hero media/actions.
- Hero: navy, wordmark + three nav links, language and real GitHub link; three-line thesis and two actions, glass sculpture on right. On mobile sculpture follows the text and actions. No hero eyebrow.
- Manifesto: open numbered two-column editorial rows, one column on mobile. Dark quotation bridge.
- Architecture: white, three underlined tabs, single diagram boundary with Core emphasized. Models and agents are distinct. Rented GPU is outside on-prem. Mobile uses native readable vertical HTML nodes. Teacher view shows candidates, evaluation and human promotion, never teacher→live GUI.
- Scientist: navy section; horizontal six-step rail; white evidence sheet with real SVG chart, computed statistics and provenance. No fake service.
- Experience: asymmetrical type/image composition; three open knowledge columns and a native promotion flow.
- Development: three status columns, exact pinned public source links, undated four-step roadmap. Closing: large navy/teal thesis and GitHub action.
- SVG directional arrows: 24px, 1.5px stroke, currentColor. Focus: 3px high-contrast outline. Motion limited to underline/control feedback, disabled for reduced motion.

Intentional corrections to Image Gen references: generated reference URLs/copy are not authoritative; only user-specified aserdargun sources and qualified planned-product copy are used. Extra reference navbar items, Linux mascot and human figures are omitted. Unavailable original Umay Ana icon is not recreated: text wordmark and a provisional typographic U favicon/apple icon are used. Closing reuses the production hero artwork to preserve the three-asset family. Full topology and all meaningful text are HTML/SVG.
